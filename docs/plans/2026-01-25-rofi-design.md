# Rofi Configuration Design
Date: 2026-01-25
Status: Abandoned

## Overview
Add a minimalist, integrated Rofi configuration to the dotfiles. Rofi will serve as the application launcher and window switcher, filling the gap in the current i3 setup.

## Architecture
The configuration will be split into two files within `dotfiles/dot_config/rofi/`:

1.  `config.rasi`: The main configuration file handling behavior, modes, and font settings.
2.  `theme.rasi.tmpl`: A templated theme file handling colors and visual layout. This uses the `.tmpl` extension to allow future dynamic coloring via Chezmoi.

## Detailed Specs

### 1. Behavior (`config.rasi`)
*   **Modes**: `drun` (desktop apps), `window` (active window switching), `run` (shell commands).
*   **Font**: "Monaspace Neon 12" (Consistent with system font).
*   **Matching**: Fuzzy matching enabled.
*   **Icons**: Disabled (Minimalist text-only style).
*   **Sorting**: Levenshtein distance or fzf-like sorting.

### 2. Visual Theme (`theme.rasi.tmpl`)
A "Catppuccin-esque" dark theme to match Alacritty/Neovim.

*   **Background**: `#1E1E2E` (Base)
*   **Foreground**: `#CDD6F4` (Text)
*   **Selection Background**: `#89B4FA` (Blue accent)
*   **Selection Text**: `#1E1E2E` (Base background for contrast)
*   **Border**: 2px solid, color `#89B4FA`.
*   **Padding**: Comfortable padding (e.g., 8px) for list items.

### 3. Integration
*   The `config.rasi` will explicitly import `theme.rasi`.
*   The `theme.rasi.tmpl` will be generated by Chezmoi during `chezmoi apply`.

## Testing Plan
1.  Run `chezmoi apply`.
2.  Launch Rofi manually: `rofi -show drun`.
3.  Verify:
    *   Window appears.
    *   Colors match the spec.
    *   Searching "term" finds "Alacritty".
    *   `Esc` closes the window.
