# Mocha flat wallpaper assets

This directory contains two project-authored, flat-vector wallpapers: a
3840×2160 landscape scene and a separately composed 2160×3840 portrait scene.
Their editable SVG sources are in `source/`; the PNGs in `landscape/` and
`portrait/` are the files referenced by the Noctalia desktop template. They
use no external images, fonts, or downloaded assets. The repository MIT
license applies; no third-party artwork is bundled.

Each runtime pool currently contains one image. This supplies stable desktop
wallpapers, not a meaningful rotation pool. Existing `landscape/`, `portrait/`,
and `omarchy/` source assets are not replaced or removed.
